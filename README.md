HelloAsso is a French payment and fundraising platform dedicated to supporting associations and non‑profit organizations. It offers free tools for online donations, event ticketing, membership management, and crowdfunding, all financed by voluntary contributions from users. The service is regulated as a payment institution in France and operates under the ESUS and ORIAS certifications, ensuring compliance and transparency for the charitable sector.

**Areas:** Crowdfunding · E‑commerce

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Helloasso: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
